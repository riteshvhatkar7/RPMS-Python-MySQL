# Recruitment & Placement Management System (RPMS)

## 1. Project Overview

The Recruitment & Placement Management System (RPMS) is designed to manage recruitment and placement activities in an organized way.

The system provides a user-friendly interface to manage candidates, companies, job openings, applications, interviews, offers, placements and reports.

This folder contains the **Frontend UI Prototype** developed using HTML, CSS and JavaScript.

## 2. Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Web Browser

## 6. How to Run the Project

1. Open the `frontend_prototype` folder.
2. Open `login.html` in a web browser.
3. Enter any non-empty demo username and password.
4. Click the Login button to navigate to the dashboard.
5. Use the sidebar to navigate between different modules.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.

## 7. Important Note

This frontend is a static UI prototype.

- The pages use sample demonstration data.
- Login is for demonstration purposes only.
- Forms demonstrate interface design and basic validation.
- Form submissions do not save records permanently.
- The frontend is not connected to the Python backend or MySQL database.

The Python and MySQL application is maintained separately in the main RPMS project.

## 8. Conclusion

The RPMS frontend prototype provides a structured and responsive interface for recruitment and placement activities. It demonstrates the major modules and navigation flow required for the Recruitment & Placement Management System.
